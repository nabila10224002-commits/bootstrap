What is HTML?

HTML (HyperText Markup Language) is the standard markup language for building web pages. It serves as the structural skeleton for every website on the Internet.

Key Concepts
  • HyperText: Interactive text that links to other documents or media.
  • Markup: Tags and annotations that specify layout and structure.
  • Language: Standardized syntax understood by all web browsers.

🏗️ How HTML Syntax Works

HTML uses tags to wrap content. Tags are enclosed in angle brackets like <tagname>. Most elements require an opening tag and a closing tag:

HTML5 
<tagname>Your content goes here</tagname>
<h1>Welcome to My Site</h1>
<p>This is an example paragraph.</p>

Basic HTML Structure

Every standard HTML5 document follows this minimal scaffold:

Template 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is my first web page.</p>
</body>
</html>
Structural Breakdown:
<!DOCTYPE html>

Declares document type as standard HTML5.

<html>

Root container for all document markup.

<head>

Stores metadata, title, scripts, and CSS links.

<body>

Contains all visible elements rendered in browser.

Essential HTML Tags

Tag Name Purpose Syntax Example
<h1> - <h6> Headings (H1 highest level to H6 lowest) <h1>Main Title</h1>
<p> Paragraphs of body text <p>Sample text...</p>
<a> Hyperlinks to internal/external URLs <a href="url">Link</a>
<img> Embedded images with alt text <img src="img.png" alt="A photo">
<div> Generic block-level division container <div>Content</div>

HTML Forms

Forms enable users to submit data and interact with web servers:

<form>
  <label for="name">Name:</label>
  <input type="text" id="name">

  <label for="email">Email:</label>
  <input type="email" id="email">

  <label for="msg">Message:</label>
  <textarea id="msg"></textarea>

  <button type="submit">Submit</button>
</form>
